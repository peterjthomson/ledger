# Ledger Privacy Policy

Effective 27 July 2026

Ledger is a macOS source-control application. It is designed to keep repository data, settings, and credentials on your Mac unless you choose to use a feature that connects to an external service.

## Data stored on your Mac

Ledger stores app settings, recent repository paths, security-scoped bookmarks, and encrypted API credentials locally. Repository contents and Git metadata are read from folders you select.

Ledger does not include advertising, cross-app tracking, or developer-operated analytics.

## Optional external services

Some features send data to a service only when you configure or invoke that service:

- GitHub features use your locally installed and authenticated GitHub CLI. GitHub may receive repository, pull-request, and comment data needed to perform the action you request.
- AI features can send prompts, code excerpts, diffs, or other user-selected content to the AI provider you enable, such as Anthropic, OpenAI, Google Gemini, or OpenRouter. This content is used to provide the requested feature and may be linked to your provider account.
- Optional notification integrations can send user-selected content to the webhook or service you configure.

Those services process data under their own terms and privacy policies. Ledger’s developer does not operate those services or receive the content sent directly to them.

## Your choices

AI providers and optional integrations are not configured by default. You can disable them or remove their locally stored credentials in Ledger’s settings. You can also manage data retained by an external service through that service’s account and privacy controls.

## Contact

For privacy questions or requests, open an issue at <https://github.com/peterjthomson/ledger/issues>.
